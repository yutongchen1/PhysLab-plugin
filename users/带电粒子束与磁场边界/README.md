# PhysLab 插件：带电粒子束与磁场边界

在 `PhysLab.1.0.0.exe` 上新增一个磁场模型，**不改动原来的「电磁·带电粒子」和「传送带」**，装完就在模型列表里多一个按钮。

| 项 | 值 |
|---|---|
| 插件 id | `beam-field` |
| 新增模型 | `beam-particle`（名称：电磁·带电粒子束与磁场边界） |
| 新增图表 | `beam_xy`（y-x 轨迹）、`beam_vt`（v-t 速率） |
| 文件 | `index.js` + `plugin.json` |

---

## 一、怎么装（30 秒）

1. 打开 PhysLab；
2. 顶部导航 → **插件市场**；
3. 点 **导入本地插件** → 选本文件夹里的 `index.js`；
4. 点 **立即重新加载**；
5. 回到「模拟」→ 模型切换里出现 **粒子束**（在「碰撞相遇」旁边），选中即可。

> 插件会存进本机 localStorage，下次打开自动带；换电脑要重新导入一次。

## 二、新增了什么

### 1. 带电粒子个数（1–12）

- `n` 粒子个数，`d` 相邻间距：整束沿**垂直于入射方向**排开，形成一条平行束；
- 每个粒子有自己的初位置，轨迹用不同颜色画在同一张图上；
- 结果页会给**每一颗粒子的出射点**和出射速度方向。

### 2. 磁场边界（圆形 / 方形）

- `R > 0` → **圆形边界**，圆心 `(xc, yc)`，半径 `R`；
- `R = 0` 且 `w、h 都 > 0` → **方形边界**，中心 `(xc, yc)`，边长 `w × h`；
- 三者都为 0 → 无边界（整片磁场，和原模型一样）；
- 画面上只画出边界范围内的 B 符号（点＝向外，叉＝向内），边界用蓝色虚线；
- **场外不受力 → 匀速直线**，所以能直接看到「直线进 → 圆弧 → 直线出」的完整过程；
- 出射点用小圆圈标出，结果页列出坐标、时刻、出射方向角。

### 3. 物理怎么算的（可以拿去对答案）

- 场区内：`B` 与 `E` 都给定时为**解析解**（圆周 + E×B 漂移），不是数值积分；
- 出射时刻用**二分法**在边界上求根，端点误差 < 1e-6 m（实测 ~1e-16）；
- 场区外：匀速直线；
- 自动校验：只有磁场时全束速率不变（实测偏差 ~1e-16）、每段端点都落在边界上。

### 4. 参数表

| 组 | 参数 | 说明 |
|---|---|---|
| 粒子 | `m` `q` `v₀` `φ` | 电荷带符号；φ 为入射方向与 +x 轴夹角（0＝沿 +x） |
| 粒子束 | `n` `d` `x₀` `y₀` | 粒子数 1–12（自动取整）、相邻间距、束的起点 |
| 场 | `B` `E` | B>0 垂直纸面向外；E 一般填 0（非 0 会叠加漂移） |
| 磁场边界 | `R` `w` `h` `x_c` `y_c` | R>0 用圆；否则 w、h 都>0 用方形 |
| 环境 | `t_max` | 模拟时长 |

### 5. 四个预设

| 预设 | 用途 |
|---|---|
| 圆形边界 · 平行束入射 | 看同一束粒子因弦长不同而偏转角不同，出射后不再平行 |
| 圆形边界 · 增大 B | B 加倍 → 半径减半，出射点更靠近入射侧（对照实验） |
| 方形边界 · 束流穿过 | 直线进、圆弧拐、直线出，边界的作用一眼看清 |
| 无边界对照 | 完整圆周运动，周期与速率无关 |

## 三、和原有电磁学插件的关系

- 原插件的 `em-particle`（电场/磁场/叠加场/导体棒）**完全不动**，两个模型可以同时存在；
- 我的模型只负责「多粒子 + 有边界」这一族题，两者参数不冲突；
- 想合并成一个插件：把本文件 `activate()` 里的 `simulateBeam` 与 `api.models.register({id:'beam-particle'…})` 整段粘到 `electromagnetism/index.js` 末尾即可（图表注册同理）。

## 四、如果要装进 exe 里（可选）

`PhysLab.1.0.0.exe` 是 NSIS 打包的 Electron 应用，解包后结构是：

```
PhysLab.exe
resources/app/
├─ main.cjs              加载 app/index.html
├─ app/index.html        整个应用（React 打包成单文件）
└─ node_modules/
```

两种做法：

1. **推荐**：不动 exe，用「插件市场 → 导入本地插件」，装一次即可（插件存在本机）；
2. **要随安装包分发**：在你的源码工程里把本插件放进 `plugins/`，重新 `npm run build` + `electron-builder` 打包（源码里插件是以 `PhysLab.definePlugin` 全局脚本形式加载的，保持这个形式即可）。

## 更新记录

### v1.0.1（修正）

**问题**：粒子离开圆形/方形边界后，轨迹仍在弯，甚至贴着边界来回绕。

**原因**：判断“当前在场内还是场外”时，用的是「当前位置是否落在边界内」；而出射点恰好**在边界上**，被判定为“仍在场内”，于是下一步又按圆周推进，在边界附近反复横跳。

**修正**：把“当前区域（场内/场外）”作为参数显式传下去，出射后一律按匀速直线推进；同时补上“擦边时给极小步长”，并把最后一段补到 t_max，保证时间轴完整。

**自测**：出射后速度方向与位置严格共线（叉积 4×10⁻¹⁶）、速率不变、速度方向不再改变；方形边界同样通过；场内速度方向持续改变（说明该转的时候在转）。
